# 💈 BookEasy

Aplicación web para gestionar reservas de citas en una barbería de forma rápida y sencilla.
Permite a los usuarios seleccionar un servicio, elegir un profesional, escoger una fecha y horario, y confirmar su reserva.

Proyecto desarrollado con React y Vite, enfocado en una interfaz moderna y limpia.
